# About Me Page Exercise

A personal landing-page exercise focused on practicing responsive layouts and visual styling with **HTML** and **CSS**.

## Highlights

- Personal introduction layout
- Responsive styling
- Custom images and branding
- Pure HTML/CSS implementation

## Tech Stack

- HTML5
- CSS3

## Run Locally

Clone the repository and open `index.html` in a browser.

```bash
git clone https://github.com/eduardolluis/About-Me-Page-Exercise.git
cd About-Me-Page-Exercise
```
